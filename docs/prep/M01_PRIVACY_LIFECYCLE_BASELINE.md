# CALPQ-M01-PREP-0013 — Privacy Lifecycle Baseline

Status: `PRE-M01 DESIGN / NO IMPLEMENTATION AUTHORIZATION`

This baseline defines how CALPQ classifies data lifecycle states, retention justifications, restricted processing states, preservation holds, review checkpoints, derived-data dependencies and terminal disposition decisions while preserving auditability and historical reproducibility.

The normative model is `docs/contracts/PRIVACY_LIFECYCLE_MODEL.md`; mandatory scenarios are in `docs/prep/M01_PRIVACY_LIFECYCLE_TEST_MATRIX.md`.
