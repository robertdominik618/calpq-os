# CALPQ M09-M12 Planning Readiness Matrix

Status: `PLANNING ONLY / BLOCKED`
ID: `CALPQ-M09-M12-READINESS-0001`

The following 40 criteria are mandatory before this planning block may be classified ready for future milestone admission.

1. M09 selective disclosure is purpose-scoped and minimum-necessary.
2. M09 original source documents are not shared by default when a narrower claim suffices.
3. M09 technical presentation validity remains distinct from issuer/verifier legal authority.
4. M09 consent does not create authority or broaden scope.
5. M09 purpose/consent records are versioned and auditable.
6. M09 external formats/protocols map through adapters/contracts.
7. M09 VC/EUDI/ISO mdoc formats do not redefine CALPQ Core semantics.
8. M09 presentations preserve claim/source/provenance/time/scope context.
9. M09 link/token/replay and audience controls are planned.
10. M09 disclosure telemetry excludes unnecessary credentials, secrets and PII.
11. M10 deterministic Core remains authoritative.
12. M10 AI cannot mark evidence VERIFIED by itself.
13. M10 AI cannot change EligibilityAssessment or AuthorizationGrant by itself.
14. M10 Next Best Action is explainable and source/gap backed.
15. M10 What-if scenarios cannot mutate authoritative state.
16. M10 conversational guidance exposes uncertainty/review requirements.
17. M10 semantic search cannot convert ranking into truth/applicability.
18. M10 document assistance remains within M05 extraction/review boundaries.
19. M10 human-review assistance leaves final accountable decision to the governed reviewer/authority.
20. M10 provider/model details remain outside Core truth semantics.
21. M11 UI consumes Application/contracts and does not own business policy.
22. M11 stale offline/cache state is distinguishable from authoritative current state.
23. M11 sensitive offline/cache data follows storage/privacy controls.
24. M11 background/notification failure does not change domain truth.
25. M11 reviewer/admin operations use explicit governed privilege paths.
26. M11 observability is diagnostic, not domain truth.
27. M11 ordinary telemetry excludes raw evidence, secrets and unnecessary PII.
28. M11 support tooling cannot bypass governed decisions.
29. M11 import/export preserves tenant/access/privacy and provenance boundaries.
30. M11 performance optimizations cannot weaken correctness/security/auditability.
31. M12 security exit evidence includes tenant/access/secrets/privilege/untrusted-content validation.
32. M12 privacy exit evidence validates purpose, retention/restriction and disclosure behavior.
33. M12 backup/restore requires consistency/reconciliation before normal exposure.
34. M12 performance/capacity testing uses production-representative workloads.
35. M12 migration/backfill plans are idempotent, checkpointed and reconciled.
36. M12 pilot rollout has bounded cohorts and rollback criteria.
37. M12 incident/support/runbooks are established for critical dependencies and recovery.
38. M12 SLO/SLI evidence is defined without becoming domain truth.
39. M12 GA requires explicit evidence-based release governance beyond CI/architecture readiness.
40. M09-M12 implementation remains blocked until separately admitted under project governance.

## Planning exit
Planning readiness requires all 40 criteria, all M09-M12 baseline/integration documents, and the planning guard to pass. Passing this matrix is not implementation or GA authorization.
