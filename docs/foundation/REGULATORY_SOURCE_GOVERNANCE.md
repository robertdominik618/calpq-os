# CALPQ Regulatory Source Governance

Status: `M00 FOUNDATION / NORMATIVE`

ID: `CALPQ-REG-0001`

CALPQ rules that depend on external authoritative material must record their source, jurisdiction, applicable dates, version and verification status. Historical decisions must retain the source version used at the time. Automated summaries or AI explanations must remain distinguishable from verified source-backed rules. Changes to source-backed rules require a controlled review before they become active.
