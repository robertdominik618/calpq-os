# CALPQ Accessibility Baseline

Status: `M00 FOUNDATION / NORMATIVE`

ID: `CALPQ-A11Y-0001`

CALPQ interfaces must be understandable, operable and perceivable for users with different access needs. Important meaning cannot rely only on color. Navigation order, labels, text scaling, error messages and platform accessibility conventions are part of acceptance criteria. Accessibility must be reviewed before release and documented exceptions require explicit approval.
